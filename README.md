# JavaScript Arrays & Loops - Friends List Project

This is a beginner JavaScript project that demonstrates how to work with arrays and loops.


## Project Goal

The goal of this project is to learn:
- How to create arrays in JavaScript
- How to access array elements
- How to use for loops
- How to build dynamic text using loops
- How to display data in HTML using DOM manipulation


##  What I learned

- How arrays store multiple values
- How to loop through arrays using a for loop
- How to use `.length` property
- How to build strings dynamically
- How to show results in the browser using DOM


## How it works

The program:
- Stores a list of friends in an array
- Uses a loop to go through each friend
- Combines them into a single text
- Displays them on the webpage
